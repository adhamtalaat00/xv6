                         SECURITY FEATURES
================================================================================

AUTHENTICATION:
  • Multi-user support (up to 32 users)
  • Unique UIDs for each user (1000+)
  • Password hashing before storage
  • Root user (UID=0) protection
  • Credential verification on access

AUTHORIZATION:
  • POSIX standard rwxrwxrwx permissions
  • Three-tier access control (user/group/other)
  • Admin (UID=0) bypass for privileged operations
  • Permission enforcement on file access
  • Executable permission validation

AUDIT:
  • 128-entry ring buffer for syscall tracking
  • PID, UID, EIP, return values logged
  • Trap names mapped to readable strings
  • Admin-only access to audit logs
  • Real-time syscall monitoring capability
